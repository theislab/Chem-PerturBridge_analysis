# Notebooks

Cross-dataset agreement and retrieval notebooks using logFC, following the original analyses documented in the [archive branch](https://github.com/theislab/Chem-PerturBridge_analysis/tree/archive).

Extensions:

- [moderated_t/](extensions/moderated_t/): moderated t-statistic agreement and retrieval.
- [direction/](extensions/direction/): direction-based retrieval.
- [review/](extensions/review/): peer-baseline comparisons for DEG agreement and retrieval.
  Code reference: the fork's `reviewer-additions-baselines` snapshot
  [e323b36](https://github.com/elmella/Chem-PerturBridge_analysis/commit/e323b360280580093a50a910cdb0dc902755c57e).
